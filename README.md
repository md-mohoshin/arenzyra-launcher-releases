# Arenzyra Observer Launcher releases

Windows installation packages and integrity metadata for Arenzyra Observer Launcher.
Application source is maintained privately. This repository contains distribution
documentation and release records, not the production application source tree.

Use a versioned release and verify the downloaded file's SHA-256 and byte size
against its `manifest.json`. Each release contains a Windows installer, a portable
ZIP, `manifest.json`, and `manifest.json.sha256`. The manifest also records the
package's signing status and verification information.

Current launcher packaging uses an explicitly unsigned distribution policy.
Windows may display an **Unknown publisher** warning. Checksums detect changed
bytes; they do not replace publisher authentication or an Authenticode signature.

Application access and licensing are controlled by Arenzyra. Public accessibility
of an installer does not grant application access or additional usage rights.
Third-party notices are included in the packages.

The developer portfolio has a separate repository and publication lifecycle.
